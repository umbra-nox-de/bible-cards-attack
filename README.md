# Bible Cards Attack

A church-themed, Pokémon-inspired card battle game proof of concept.

## Version 0.1
- Local Practice Battle
- Prayer resource system
- Character HP and attacks
- Simple Training Pharaoh AI
- Support card demonstration
- Collection page
- Future Mythical unlock placeholders

## Run locally

```bash
npm install
npm run dev
```

Built as a proof of concept for a youth class.


## Deployment
This project deploys automatically to GitHub Pages when `main` is updated.
